# Versioning

`nc-protocol` uses SemVer `MAJOR.MINOR.PATCH`.

## MAJOR

Backward-incompatible wire change: field removal/rename, semantic
incompatibility, required behavior change, incompatible MCP public
contract change.

## MINOR

Backward-compatible addition: new optional field, new optional
capability, new backward-compatible message/tool schema, feature
extension.

## PATCH

Backward-compatible correction: validation fix, schema metadata or
documentation fix, any change that does not alter wire behavior.
